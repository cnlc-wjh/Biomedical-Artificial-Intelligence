# Course Data Report

将课程材料转化为一份与题目一致、数值可复核的报告，并提供能重现结果的代码。适用于 PPT 或工作单规定任务、数据文件提供实证材料、用户另给一份报告作为排版参照的情形。

## 理解任务

1. 先读取 PPT 的全部相关页面、学生工作单、数据字典、作业说明和用户提供的参考报告。区分必交要求、课堂示例与可选延伸。若资料彼此冲突，指出冲突并以明确的用户要求为先；不要默默拼接不同版本的数据。
2. 对数据做结构核查：行的含义、唯一标识、编码、变量类型、单位、组别人数、缺失、重复及取值异常。明确分析单位、研究对象、目标参数和实际纳入规则。不要把空白数值替换成零，也不要把全体人数写成某项检验的样本量。
3. 在计算结果前从题目确定主要终点、比较方向、假设、显著性标准与主要方法。若这些只是在接触数据后确定，应诚实标为探索性；不要声称已经预注册。其他模型或分层分析要与主分析明确区分。

## 计算与写作

1. 选择与研究设计、变量类型和目标参数匹配的方法。写出关键条件与备选方法；仅在数据真实包含相应记录时执行分析，例如没有患者前后测量时只讨论配对检验的选择，不编造随访结果。
2. 提供可独立运行的分析脚本。脚本以自身位置定位输入，保留原始数据，输出必要的统计表和图。用第二种合理计算路径核对关键数值，例如公式与统计库互核；记录依赖版本、数据文件哈希和运行命令。
3. 报告各组实际 n、描述统计、具单位的效应估计、置信区间、p 值和统计决策。解释统计证据、实际或临床意义以及因果边界。p 值不是原假设为真的概率；未拒绝原假设也不等于证明没有效应。
4. 检查缺失、混杂、来源中心、离群值和多重比较对结论的影响。敏感性分析只写实际运行的结果；计划中的插补、验证或模型要明确写成计划。观察性关联不得改写为治疗效果或因果作用。
5. 若作业要求另选研究问题，单独写前瞻性设计，包含对象、终点、H0/H1、变量类型、主方法与备选、至少两个候选混杂因素、比较控制、报告计划和结论边界；不虚构实证结果。

## 文档与讲解

参照用户指定的文档提取实际页面、页边距、字体、标题层级、正文段距、图题与表格规则，并在本次报告中一致应用。若指定的是本项目上一章的 PCA/UMAP 报告，读取 [references/pca-report-format.md](references/pca-report-format.md) 作为具体参照；若用户另给模板，以新模板为准。避免把参考报告的题目内容或其旧统计值带入新报告。

生成 Word 报告后，核对文件结构、表格宽度、图中文字及数值一致性，并尽可能渲染每页检查截断、跨页表格、图题和字体。渲染不可用时，在交付说明中明确该验证限制，不声称已完成视觉检查。

用户要求学习时，先给报告、代码和运行入口，再按概念分段讲解。每次只展开一个知识模块，并结合报告中的实际参数、公式和代码；在用户提问后先解决疑问，再进入下一模块。不要在一次回复中倾倒全部课程内容。
