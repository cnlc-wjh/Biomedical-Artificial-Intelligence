# PCA/UMAP 参考报告版式

仅在用户指定 `降维PCA与UMAP报告.docx` 为排版参照时使用。优先以实际 DOCX 的样式与渲染结果为准；以下是从本次提供的参考文件提取的规格，适合做初始设置。

| 项目 | 参考设置 |
|---|---|
| 纸张 | Letter，约 21.59 × 27.94 cm |
| 页边距 | 上下 2.54 cm；左右 3.18 cm |
| 中文正文 | 宋体，约 10.5 pt；西文 Times New Roman |
| 正文段落 | 首行缩进约 0.74 cm；1.25 倍行距 |
| 主标题 | 居中、黑体、约 22 pt、加粗 |
| 一级正文标题 | 黑体、约 15 pt、加粗；与后段同页 |
| 次级标题 | 黑体、约 12 pt、加粗；与后段同页 |
| 表格 | 居中三线表；顶部和底部较粗线，表头下细线，无竖线；表头加粗，单元格文字约 10.5 pt |
| 图片 | 居中；宽度不超过正文宽度；图题紧随图片、居中 |

这些数值是本次用户所给参考稿的版式记录，不应强制应用于所有课程报告。创建新报告时，优先复用参考 DOCX 的节设置与样式，再根据新内容检查表格列宽和分页。避免把参考稿的正文、结论、作者信息或旧图片复制进新报告。
